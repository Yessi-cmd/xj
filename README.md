# 玄鉴 · 命理投研罗盘

玄鉴是 AShare 的独立前端原型：用传统八字和五行画像理解用户偏好，再以 AShare 量化因子与组合约束生成股票、基金研究候选。

## 当前能力

- `/`：公开品牌首页与方法边界。
- `/demo`：无需登录的完整交互演示，数据仅在浏览器中计算。
- `/dashboard`：使用平台托管的 ChatGPT 登录保护个人工作台。
- 公历出生日期、时辰、性别、出生城市与简化真太阳时校正。
- 四柱、五行分布、日主、简化喜用倾向与投资风格画像。
- 将五行倾向映射到 `quality / growth / value / momentum / low_risk` 五因子。
- 股票与基金候选展示；当前候选和量化分是固定原型样本。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

验证生产构建与服务端渲染：

```bash
npm test
```

## 设计边界

组合分数暂定为：`AShare 量化基础分 × 85% + 命理偏好匹配 × 15%`。命理层只能调整通过量化可交易性筛选后的候选排序，不能绕过 ST、流动性、上市时间、行业权重和个股权重约束。

风水命理缺乏可重复验证的金融预测证据。本项目将其定位为传统文化体验和投资偏好表达，不作为收益预测或买卖依据。

完整的后端接入与上线分期见 [`../docs/fortune-site-architecture.md`](../docs/fortune-site-architecture.md)。

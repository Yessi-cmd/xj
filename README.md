# 玄鉴 · 每日玄签

玄鉴是一个独立部署的传统命理娱乐网站：用出生时空生成本命盘，再将本命、北京时间流日、股票出生标签与用户反馈合成每日六枚 A 股玄签。

推算完成后，结果标题下首先呈现六张签卡，流日罗盘与宜忌解读位于签卡之后；命签仅供文化娱乐，不构成投资建议。

线上地址：[xj.norliva.top](https://xj.norliva.top)

## 当前能力

- `/`：公开品牌首页。
- `/live`：VPS 公网入口；构建后会输出为静态首页。
- `/demo`：无需登录的完整体验。
- `/dashboard`：使用平台托管登录保护的个人工作台。
- 工作台侧边导航在桌面端从左缘悬停或聚焦时展开，内容区随之重排；手机端使用左侧抽屉，支持菜单按钮、边缘右滑打开和左滑关闭。
- 首页与公开体验入口展示北京时间流日风水概览，以及带交易日、更新时间和距今天数的三大指数静态快照；两者明确分栏。
- 新档案不再预填示例生辰：性别、出生日期和出生地点必须由用户明确选择。出生日期支持公历或农历录入（含闰月），农历在本机换算为公历后进入同一套四柱逻辑；全国 3,304 个县市地点按“省级 → 市级 → 县区级”逐级选择，并支持各级名称筛选、出生地经度校正、四柱五行与本命称号。出生时间默认不要求，用户可自主开启以提高测算精度。
- 本命录入以表单为主、罗盘为辅助装饰：桌面端压缩罗盘占比，平板和手机端自适应为单列，成对输入控件保持水平对齐。
- 本命守护、今日上签、潜龙、同曜、补运、相冲六种命签；静态行业、财务和历史涨跌资料默认折叠，与文化命签分层呈现。
- 已保存档案在北京时间跨日后回到开签界面，不继续展示昨日命签；只有用户主动开签后才计入连续天数，同日再次进入则恢复当天已锁定结果。
- 每日可无限次换卦；每次只改变上签、潜龙、同曜和补运，守护签和相冲签保持不变。
- “有缘、无感、避开”反馈、七日重复冷却、缘分册和三十日星轨。
- 浏览器本地状态与 AES-GCM 加密 `.xjprofile` 导入导出；跨设备迁移默认收纳在折叠式“档案工具”中。导入可先选文件再输入密码，解密成功后仍需确认覆盖；导出要求已有档案且密码至少六位。
- 1080×1440 隐私分享卡，不包含原始生辰和地点。
- 4991 只 A 股的五行、星曜、神兽、卦宫、灵数、上市日柱与行业标签。首轮排序只加载紧凑索引，六签确定后再从本站静态分片补齐对应股票事实资料。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

验证严格类型、完整构建、页面渲染、每日命签、反馈状态和加密档案：

```bash
npm test
```

也可分别运行 `npm run typecheck`、`npm run lint` 和 `npm run data:check`。`npm run data:runtime` 会由完整标签池重新生成紧凑索引与事实分片，普通构建会自动执行它。

生成 VPS 静态发布目录：

```bash
npm run build:vps
```

刷新交易所上市资料与股票命理标签：

```bash
npm run data:refresh
```

该命令通过 AkShare 在构建阶段读取沪、深、北交易所批量证券资料；网站运行时不请求行情或推荐接口。

显式刷新首页大盘快照：

```bash
npm run data:market
```

该命令在维护阶段读取东方财富行情中心的上证指数、深证成指和创业板指，写入版本化的 `app/data/market-snapshot.json`。页面只展示随站点发布的延时或收盘快照，并始终标出交易日与更新时间；页面加载时不请求行情接口。

显式刷新全国县市与经度快照：

```bash
npm run data:locations
```

行政区划名称来自民政部 2026 年版数据，县市中心经度在维护阶段合并为 `app/data/china-locations.json`。网页只读取随站点发布的静态快照，不在运行时调用地图、定位或地名接口。

刷新股票基本面快照（总市值、市盈率、当日与 5 日涨跌幅、主营业务简介、主营收入与报告期）在 VPS 上执行抓取，再把结果回传合并：

```bash
# 在 VPS 上（有 Python3 与干净网络）
python3 scripts/fetch-stock-facts.py /var/www/xj.norliva.top/current/data/mystic-stocks.json
# 回传 var/stock-facts.json 后本地合并，schemaVersion 升 4
npm run data:facts:merge
```

快照来自腾讯行情与东方财富 F10，随部署静态发布并标注交易日；总市值以亿元保存，F10 主营收入以人民币元保存并在展示层换算。个股缺失字段保持为空，页面只读取本站同版本的静态事实分片，不会在运行时请求腾讯、东方财富或其他第三方行情接口。

`npm run build:vps` 会先严格执行数据新鲜度检查：大盘交易日默认不得早于构建日 7 天，个股事实快照默认不得早于 14 天。维护者应先显式刷新相应快照，不能靠普通构建偷偷联网。

## 数据与产品边界

每日缘分分由本命共振 45%、今日流日 25%、小众探索 15%、用户缘感 10% 和基础资格 5% 构成，并按固定阈值映射为 S（≥80）、A（≥70）、B（≥60）、C（≥50）、D（<50）五档展示评级；评级只作展示层级，不参与排序。本命档案还提供可选进阶信息：幸运数字、行业偏好、守护神兽、晨昏偏好与血型——守护神兽成为本命神兽、晨昏偏好决定本命阴阳、血型参与本命主星分配、幸运数字与行业偏好在本命维度小幅加分，全部并入本命指纹，同输入同结果。反馈只能在命理候选中轻微调整未来顺序，不改变当天已经锁定的命签；无感反馈三十天后自动淡出，有缘与避开长期保留。守护签随本命盘恒定，尊重无感与避开名单，不受七日冷却与换卦影响。

风水命理缺乏可重复验证的金融预测证据。流日风水只描述文化取象，大盘卡只描述已发生的指数变化，两者不建立因果关系。本站定位为传统文化娱乐体验，不提供买入、卖出、收益或涨跌预测。

技术边界和部署结构见 [`docs/architecture.md`](docs/architecture.md)。

换卦使用玄青鎏金风格的站内确认弹窗，支持键盘操作与 Esc 取消。股票静态事实资料默认折叠，展开后在独立滚动区域展示完整简介，不截断正文；可通过触摸、滚轮和键盘查看。

## RackNerd 低流量自动更新

- RackNerd 使用 `xuanjian-data-update.timer`，按北京时间周一至周五 16:30 执行，随机延迟不超过两分钟；`Persistent=true` 在服务器恢复后补触发。运行前用文件锁避免重复抓取。
- 先用一次三大指数请求检查交易日；交易日未变化时跳过股票抓取和发布（节假日也不会重复全量下载）。每个新交易日刷新批量行情，并在服务器保留最近三十个收盘快照；只请求一次上证指数六根日线来确定五个交易日边界，用对应两日真实收盘价计算五日收盘涨跌（未复权）。未积累够六个交易日或对应日期缺失时，该字段留空，不逐股请求 K 线。公司简介、真实行业和营收等 F10 资料至少间隔七天刷新一次，不再跨日复用 `/tmp` 断点文件。
- 公司资料请求缺失时保留上次真实字段；当日行情缺失字段为空，不伪造新值。发布要求当日行情覆盖率至少 95%、每周公司概况和营收同时有效的覆盖率至少 90%，否则保留当前线上版本。
- 维护源码在 `/opt/xuanjian-updater/source`，独立 Node 运行环境在 `/opt/xuanjian-updater/node`。首次安装依赖后，每日复用依赖在 VPS 本地执行 `npm run build:vps`，不进行 npm 安装或整站往返上传。`scripts/update-vps-data.py` 更新版本化源数据，`scripts/validate-data-release.py` 校验完整池、索引及全部事实分片；构建完成后创建 `auto-data-*` release 并原子切换 `current`，HTTP 或安全头检查失败会切回上一版本。
- `/var/log/xuanjian-data-update.log` 记录抓取请求次数、成功响应体字节数、跳过原因和发布结果（字节数不含 TCP/TLS、HTTP 头以及失败响应流量）；日志每周轮转、压缩，保留八份。`/var/lib/xuanjian-updater/last-success` 和 `last-failure` 保存最近成功、失败记录。使用 `systemctl status xuanjian-data-update.service` 和 `systemctl list-timers xuanjian-data-update.timer` 排查执行状态。
- 三大指数静态快照同时发布为 `data/market-snapshot.json`，页面仍展示构建时注入的版本化数据；生产浏览器不请求第三方行情接口。每周公司资料的抓取时间记录在 `factsSnapshot.profilesCapturedAt`，旧快照缺少该字段时首次执行会刷新公司资料。
- 离线维护测试：`python3 -m unittest discover -s tests -p '*test.py'`；该测试不访问行情源。常规应用验证仍执行 `npm run lint`、`npm test`。
自动更新的大盘首选东方财富；其接口不可用时读取腾讯同一组三大指数的真实收盘数据，并在页面来源字段中标明腾讯行情。不会用旧值推算或填造指数。

后续代码发布必须同步维护源码和 .updater-source-id 标识。自动任务发现线上 release 与维护源码标识不一致时会停止，避免翌日定时构建覆盖人工发布的新功能；初始化显式使用 --force。

完整股票源的 schemaVersion 升为 4，股票命理 tagVersion 仍为 3.0；排序规则不变。五日收盘涨跌明确为未复权口径，自动更新只用真实收盘缓存和指数给出的交易日边界计算，不足时为空。

自动生成的 auto-data-* release 保留最近十四个，并额外保护当前及上一个版本；不会清理原有人工发布版本。公司资料断点只在同一周度抓取周期且未超过七天时复用，成功完成后从该周期最早抓取时间计算下一次刷新。

若服务器在周五收盘后未完成更新、到周末才恢复，持久定时器补触发仍会核对最新交易日并补齐；已保存周五收盘的周末执行直接跳过，不产生行情请求。
